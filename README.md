# 嘉禾志愿（微信小程序）

嘉禾志愿的志愿服务平台小程序：志愿者注册与实名认证、活动发布与报名签到、培训、积分与爱心商城，一套完整的小程序端 + 云端接口。

## 功能

- **账号与认证**：微信登录、手机号绑定、实名认证、个人资料与密码管理；
- **志愿活动**：活动列表与详情、在线报名、活动签到、我的活动；
- **培训**：志愿者培训内容与记录；
- **积分体系**：志愿服务积分查询与明细；
- **爱心商城**：商品列表与详情（积分相关）；
- **快捷入口**：常用操作快捷通道、关于页面。

## 技术构成

- 小程序端：微信原生小程序（TypeScript + Sass），位于 `miniprogram/`；
- 服务端：接口与注册相关服务位于 `workers/`、`register/` 目录，数据迁移位于 `p8-3-migration/`；
- 工程配置：`project.config.json`（微信开发者工具项目配置）。

## 目录

```
├── miniprogram/     # 小程序源码（pages：活动/培训/商城/积分/签到/个人中心等）
├── workers/         # 后台 Worker 服务
├── register/        # 注册相关服务
├── p8-3-migration/  # 数据迁移
├── images/          # 小程序图片资源
├── docs/            # 项目文档
└── project.config.json
```

## 开发

使用微信开发者工具导入本仓库，AppID 与后端接口地址按 `project.config.json` 及各环境配置填入后即可编译预览。
